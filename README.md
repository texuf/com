# texuf.com

Static homepage. Displays "texuf" scaled to fill 2/3 of the viewport using [@chenglou/pretext](https://github.com/chenglou/pretext) for text measurement.

## Setup

```sh
bun install
```

## Development

```sh
bun run build
```

Output is in `dist/`.

## Deploy

Cloudflare Pages:

- Build command: `bun run build`
- Output directory: `dist`
